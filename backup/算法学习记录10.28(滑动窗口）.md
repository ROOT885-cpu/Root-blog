滑动窗口模板题，本质是求长度为k的所有子串，元音字符的数量。
1.先枚举右端点，vow变量是窗口长度
2. 确定窗口左边界
窗口大小固定为 k，当前右边界是 i,则：left = i - k + 1,
当 left < 0 时，说明窗口还没凑满 k 个字符，跳过统计（continue）。
当 left >= 0 时，窗口 [left, i] 恰好长度为 k，此时更新答案。
3. 更新答案并提前剪枝
ans = max(ans, vow);
if (ans == k) break;   // 已经达到理论最大值，无需继续
4. 移出窗口左边界的字符
窗口右移一位后，原来的 s[left] 会离开窗口：if (out 是元音) vow--;
写这题时还不是很熟悉continue的作用，是跳过本轮循环。
